## Design Context

### Users
usmoment serves developers and product builders who are exploring reusable capability components for relationship-centered products. They come to the docs site to understand the project philosophy, package layers, component capabilities, and integration paths without losing sight of the warm product origin behind the system.

### Brand Personality
The brand should feel warm, trustworthy, and light. It represents "our moments" and should carry emotional continuity rather than a purely technical or commercial tone. The interface should help users feel calm confidence, human closeness, and curiosity.

### Aesthetic Direction
The docs site should use a soft light theme built around the brand colors `--usmoment-yellow: #FFC600` and `--usmoment-orange: #FF6400`. The visual language should be gentle and memorable, with warm off-white surfaces, charcoal text, restrained orange accents, and logo-inspired brush or glow effects. It should avoid aggressive contrast, salesy landing-page tropes, and overly commercial SaaS styling.

### Design Principles
- Keep the homepage introduction-only while making the brand immediately recognizable through the logo, warm brush motif, and system-level story.
- Use yellow as the warm atmospheric color and orange as a focused accent, avoiding large saturated blocks that feel promotional or harsh.
- Preserve the docs site's practical navigation model: left-aligned logo and tabs, right-aligned language selection, with a translucent glass header.
- Add one signature hero animation inspired by the logo brush, while respecting `prefers-reduced-motion` so motion-sensitive users get a stable experience.
- Keep style ownership focused inside `docs/site-react`, with CSS split by concern and no runtime package class leakage.
